# Third-party software

Glöwr ships with the following open-source components.

| Component | Licence | Use |
| --- | --- | --- |
| [lamejs](https://github.com/zhuker/lamejs) 1.2.1 | LGPL-3.0 | MP3 encoding. Shipped unmodified as its own file (`vendor/lame.min.js`) so it can be replaced; its licence is in `vendor/lamejs-LICENSE.txt`. |
| [Lucide](https://lucide.dev) | ISC | Interface icons, bundled. |
| [webextension-polyfill](https://github.com/mozilla/webextension-polyfill) | MPL-2.0 | Promise-based `browser.*` API in Chromium, bundled unmodified. |
